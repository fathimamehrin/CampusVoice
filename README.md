# CampusVoice – Online Complaint Management System

CampusVoice is a web-based complaint management system developed using Django. It provides a platform for students to submit and track complaints, while administrators can manage complaints and update their status.

## Features

- Student Registration and Login
- Submit Complaints
- View and Track Complaints
- Edit Pending Complaints
- Delete Pending Complaints
- Admin Dashboard
- Complaint Status Management

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS

## Complaint Categories

- Technical
- Academic
- Facilities
- Other

## Complaint Status

- Pending
- In Progress
- Resolved

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/fathimamehrin/CampusVoice.git`

2. Navigate to the project directory:

   `cd CampusVoice`

3. Create a virtual environment:

   `python -m venv venv`

4. Activate the virtual environment:

   `venv\Scripts\activate`

5. Install Django:

   `pip install django`

6. Apply migrations:

   `python manage.py migrate`

7. Run the development server:

   `python manage.py runserver`

8. Open your browser and visit:

   `http://127.0.0.1:8000/`
